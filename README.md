# Echo Ridge

Single-player computer sniper-game foundation built for Godot 4.

## Run
Import project.godot into Godot 4 and press F6 with main.tscn open, or F5 to run the project.

## Current implementation
Procedural 3D test environment, first-person movement, collision, mouse aiming, zoom, hitscan target shooting, five-shot magazine, immediate refill, intel collection, extraction and restart.

## Status
Initial untested foundation, not a AAA game or finished release. No engine execution or visual playtest has been performed. Targets are stationary blocks, not functioning enemy AI. Shooting is hitscan; wind, bullet travel, reload animation, audio, save/load, navigation and production art are not implemented. Escape releases the mouse but does not pause simulation. R immediately refills ammunition for development testing.

## Next milestones
Engine validation and packaged Windows build; automated smoke tests; movement and weapon polish; projectile simulation; AI navigation and search; checkpoints and settings; original environment art and audio; measured performance and visual QA.
